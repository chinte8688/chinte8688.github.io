# 米宝弁当 - 訂便當系統

線上便當訂購頁面，基於米宝弁当（MiBo Bento）菜單建立。

## 檔案

| 檔案 | 用途 |
|------|------|
| `bento.html` | 前台點餐頁面 |
| `admin.html` | 後台管理與統計 |

## 點餐頁功能

| 功能 | 說明 |
|------|------|
| 養生便當系列 | 糙米高纖、紅豆什穀、減醣、京醬滷排、黃金排骨、碳烤豚肋排、魚排 |
| 本店特色便當 | 正宗池上、懷舊排骨、雞腿、雞排（特價）、宮保雞丁、柳葉魚、蒲燒虱目魚、鰻魚 |
| 單點加購 | 各式主食單點、雞排、雞腿、四季春茶 |
| 飯類加價 | 白飯（含）、糙米飯 / 紅豆飯（+15） |
| 購物車 | 浮動按鈕、數量增減、刪除、合計金額 |
| 訂單送出 | 送出後寫入 localStorage，後台可讀取 |

## 後台管理功能

| 功能 | 說明 |
|------|------|
| 統計卡片 | 總訂單數、總便當數量、總營收、平均客单價、最暢銷商品 |
| 訂單明細 | 可依日期、狀態、關鍵字篩選，可修改狀態（已完成/待處理/已取消）或刪除 |
| 銷售排行 | 便當銷量 Top 15 長條圖 |
| 營收排行 | 商品營收貢獻 Top 15 |
| 每日統計 | 每日訂單數與營收走勢 |
| 分類統計 | 養生系列 / 特色便當 / 單點 / 飲料 分類銷量 |
| 匯出 CSV | 一鍵匯出全部訂單 |
| 清除資料 | 二次確認後清除所有訂單 |

## 使用方式

```
雙擊 bento.html   → 點餐
雙擊 admin.html   → 後台管理
```

資料透過 localStorage 共享，同一瀏覽器即可同步。

## 技術

- 純 HTML + CSS + JavaScript，無第三方依賴
- RWD 響應式設計，支援手機與桌面瀏覽器
- localStorage 持久化訂單資料
