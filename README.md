# 米宝弁当 - 訂便當系統

線上便當訂購頁面，基於米宝弁当（MiBo Bento）菜單建立。

## 檔案

- `bento.html` — 單檔 HTML，無需安裝，瀏覽器直接開啟即可使用。

## 功能

| 功能 | 說明 |
|------|------|
| 養生便當系列 | 糙米高纖、紅豆什穀、減醣、京醬滷排、黃金排骨、碳烤豚肋排、魚排 |
| 本店特色便當 | 正宗池上、懷舊排骨、雞腿、雞排（特價）、宮保雞丁、柳葉魚、蒲燒虱目魚、鰻魚 |
| 單點加購 | 各式主食單點、雞排、雞腿、四季春茶 |
| 飯類加價 | 白飯（含）、糙米飯 / 紅豆飯（+15） |
| 購物車 | 浮動購物車按鈕、數量增減、刪除、合計金額 |
| 訂單送出 | 彈出確認視窗，顯示明細與合計 |

## 使用方式

```
雙擊 bento.html 開啟
```

## 技術

- 純 HTML + CSS + JavaScript，無第三方依賴
- RWD 響應式設計，支援手機與桌面瀏覽器
